# Asset and IP Policy

- Prefer procedural geometry, original textures, and self-created audio.
- Do not use third-party assets unless the license permits this use and attribution obligations are recorded.
- Do not include logos, branding, or imply affiliation with any real aerospace company or space agency.
- The rocket can be inspired by the broad silhouette and reusable launch concept of contemporary heavy-lift vehicles, but should have original design details and no copied trademarks.
- For a later Earth texture or station model, record source, license, attribution text and any restrictions in `docs/ASSET_CREDITS.md`.
- Keep a placeholder option so the game still runs if an optional asset fails to load.
